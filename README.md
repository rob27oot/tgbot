# 🤖 بوت تنزيل الفيديوهات (تيك توك + تويتر)

بوت تيليجرام عربي لتنزيل فيديوهات تيك توك وتويتر (X)، مع اشتراكات بنجوم تيليجرام (Stars)، إحصائيات، تبرعات، ودعم.

## المميزات

- 🎬 تنزيل من تيك توك وتويتر بأعلى جودة (yt-dlp + خطة بديلة لتويتر)
- ⭐ اشتراكات بنجوم تيليجرام مع حماية من تكرار الدفع
- 📊 إحصائيات للمستخدم، وإحصائيات كلية للمشرفين
- 💰 تبرع (رقم ماستر + نجوم)
- 🆘 دعم: رابط مباشر + رسائل تنحفظ بجدول `support_tickets`
- 🚦 حد 3 تنزيلات بالدقيقة لكل مستخدم، وتنزيل واحد فقط بنفس الوقت

## المتطلبات

- Python 3.11 أو أعلى
- توكن بوت من @BotFather
- (اختياري) ffmpeg لجودة أفضل

## التشغيل داخل VS Code

### 1) فتح المشروع

File ← Open Folder ← اختر مجلد `tgbot`، وافتح Terminal بـ Ctrl + `

### 2) انشاء البيئة الافتراضية

Windows:

```powershell
python -m venv venv
venv\Scripts\activate
```

Mac / Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3) تثبيت الحزم

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4) اعداد ملف `.env`

انسخ `.env.example` الى `.env` وعبّي القيم:

```env
BOT_TOKEN=توكنك_من_BotFather
MASTER_PHONE=رقم_الماستر
SUPPORT_USERNAME=يوزر_الدعم_بدون_@
ADMIN_IDS=ايديك_من_userinfobot
DATABASE_URL=sqlite+aiosqlite:///./bot.db
MAX_FILE_SIZE_MB=50
DAILY_FREE_DOWNLOADS=3
```

> ⚠️ لا ترسل التوكن لأحد ولا ترفع ملف `.env` على GitHub.

### 5) التشغيل

```powershell
python -m bot.main
```

لازم يطلع: `Bot started as @اسم_البوت`. ايقاف البوت: `Ctrl + C`.

## التشغيل بـ Docker (اختياري)

```bash
docker compose up -d --build
```

تحديث yt-dlp (مهم، تيك توك وتويتر يتغيرون باستمرار):

## اختبار سريع

شغّل البوت (`python -m bot.main`) وجرّب من تيليجرام:

| # | الاختبار | النتيجة المتوقعة |
|---|----------|------------------|
| 1 | ارسل `/start` | تطلع القائمة الرئيسية بالأزرار |
| 2 | 🎬 تنزيل مقطع ← تيك توك ← ارسل رابط فيديو عام | ينزل الفيديو مع العنوان والمدة والحجم والجودة |
| 3 | نفس الشي مع تويتر (تغريدة فيها فيديو) | ينزل الفيديو |
| 4 | ارسل رابط خطأ مثل `https://google.com` | رسالة "الرابط غير صالح" |
| 5 | ارسل 4 روابط بسرعة | الرابع يرد "انتظر ... ثانية" |
| 6 | 📊 إحصائياتي | تظهر ارقامك، وللمشرف قسم اضافي للبوت |
| 7 | 💰 التبرع | يظهر رقم الماستر قابل للنسخ + أزرار النجوم |
| 8 | 🆘 الدعم ← إرسال رسالة للمشرف | توصل رسالة للمشرف ويرجعلك رقم التذكرة |
| 9 | ⭐ الاشتراك ← اختر باقة | تطلع فاتورة بالنجوم (اضغط إغلاق اذا ما تريد تدفع) |
| 10 | بعد الدفع (تبرع 10 ⭐ للتجربة) | رسالة شكر، وتظهر النجوم بإحصائيات المشرف |

اختبار وضع الحصة: غيّر `DAILY_FREE_DOWNLOADS=1` بـ `.env`، اعد التشغيل، نزّل فيديوين: الثاني لازم يرفضه ويعرض الاشتراك.

## مراجعة ما قبل الإنتاج (5 نقاط)

1. **الأمان والتوكن:** سوِّ Revoke لأي توكن انكشف بالشات أو الصور، وتأكد `.env` مو مرفوع، وصلاحيات السيرفر محصورة.
2. **الاعتماد على yt-dlp وخدمة fxtwitter:** تيك توك وتويتر يغيّرون طريقتهم باستمرار، فحدّث yt-dlp دورياً. وfxtwitter خدمة طرف ثالث، لو وقفت يرجع المحتوى الحساس بتويتر يفشل. راقب `bot.log`.
3. **الدفع بالنجوم:** جرّب الدفع بنفسك بمبلغ صغير. جهّز آلية للاسترجاع (refund) والمراجعة لو صارت شكوى، وراجع تنبيهات "دفعة بحاجة مراجعة" اللي توصل للمشرف.
4. **قاعدة البيانات والذاكرة:** SQLite تكفي لعدد قليل، ومع نمو المستخدمين انتقل لـ PostgreSQL (بس غيّر `DATABASE_URL`). خذ نسخة احتياطية دورية من `bot.db`. وحدّ الطلبات محفوظ بالذاكرة فيتصفّر عند اعادة التشغيل، ولا يشتغل صح إذا شغّلت أكثر من نسخة.
5. **الحدود والشروط القانونية:** حد تيليجرام للبوتات 50MB (لأكثر استخدم local Bot API). وتنزيل المحتوى قد يخالف شروط تيك توك وتويتر وحقوق المنشئين، فراجع هذا قبل ما تفتح البوت للعموم أو تستلم عليه أموال.

## مشاكل شائعة

| المشكلة | الحل |
|---|---|
| `BOT_TOKEN فارغ` | تأكد من ملف `.env` وانه محفوظ |
| `Conflict: terminated by other getUpdates` | في نسخة ثانية من البوت شغالة، سكّرها |
| تيك توك `Unexpected response` | نصّب `pip install -U "yt-dlp[default,curl-cffi]"` |
| تويتر `No video could be found` | تغريدة حساسة، الخطة البديلة تتعامل وياها تلقائياً |
